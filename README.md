
# KHAYRNA 3D CAMPUS

الحرم الجامعي الافتراضي ثلاثي الأبعاد لخيرنا.

## 1. وصف المشروع

مشروع لإنشاء بيئة جامعية افتراضية ثلاثية الأبعاد تعمل داخل متصفح الإنترنت.

تتيح البيئة استضافة المؤسسات الأكاديمية والبحثية، والمباني والمرافق المشتركة، ووكلاء الذكاء الاصطناعي.

المشروع مستقل مكانيًا عن المؤسسات التي يستضيفها، وقابل للتوسع لاستضافة أكاديميات وجامعات ومراكز بحثية أخرى مستقبلًا.

## 2. التقنيات المستخدمة

- React
- TypeScript
- Vite
- Babylon.js
- WebGL 2

## 4. تشغيل المشروع

تأكد من تثبيت Node.js أولًا.

ثم افتح الطرفية داخل مجلد المشروع ونفّذ:

```bash
npm install
```

لتشغيل بيئة التطوير:

```bash
npm run dev
```

لبناء نسخة الإنتاج:

```bash
npm run build
```

## 5. المكونات الحالية

- مشهد ثلاثي الأبعاد للحرم.
- أرض وساحة وطرق أساسية.
- مبانٍ تجريبية.
- وكلاء افتراضيون تجريبيون.
- كاميرا قابلة للتحريك والتقريب.
- اختيار المباني والوكلاء.
- لوحة معلومات عربية.
- واجهة متجاوبة مع الشاشات المختلفة.

## 6. مراحل التطوير المستقبلية

1. تطوير التصميم المعماري الواقعي للمباني.
2. إضافة الطوابق والغرف والممرات.
3. دعم الدخول إلى المباني واستكشافها.
4. إضافة نظام ملاحة داخل الحرم.
5. إنشاء نظام إدارة المؤسسات والمرافق.
6. إضافة نظام إدارة الوكلاء.
7. تطوير نظام حفظ المواقع والحالة المكانية.
8. إضافة الأصول ثلاثية الأبعاد بصيغة glTF وGLB.
9. ربط قواعد البيانات بعد تصميمها واعتمادها.
10. إضافة أنظمة المحاكاة والتوائم الرقمية مستقبلًا.

## 7. مبدأ معماري أساسي

الحرم الجامعي محرك مكاني مستقل.

المؤسسات الأكاديمية والبحثية كيانات مستقلة يمكنها استخدام المباني والمرافق وفق علاقات ملكية أو تخصيص أو مشاركة.

لا يُفترض أن كل مبنى يتبع مؤسسة واحدة فقط.
