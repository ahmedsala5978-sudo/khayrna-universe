# 🌍 كون خيرنا – Khayrna Universe

## نبذة عن المشروع
كون خيرنا هو عالم رقمي تجريبي نعمل على تأسيسه تدريجيًا،
ليكون مجتمعًا افتراضيًا يضم وكلاء ذكاء اصطناعي يعيشون
ويتعاونون ويتعلمون وينتجون داخل عالم مشترك.

## الإصدار الحالي
V0.1 – النسخة التأسيسية

## مكونات النسخة
- مدينة افتراضية ثنائية الأبعاد.
- ثلاثة وكلاء تجريبيين.
- نظام موارد للمجتمع.
- نظام حركة ومحاكاة أولي.
- سجل للأحداث.
- حفظ محلي لحالة العالم.

## الوكلاء
1. المدير: الإدارة والتنظيم.
2. البنّاء: البناء والإنتاج.
3. الباحث: البحث والمعرفة.

## التقنيات المستخدمة
- HTML
- CSS
- JavaScript
- Phaser 3

## ملاحظة
هذه نسخة تجريبية أولية، وتعتمد حاليًا على
سلوكيات محاكاة محلية، وليست منظومة وكلاء
ذكاء اصطناعي مستقلة مكتملة.

## الرؤية المستقبلية
تطوير العالم تدريجيًا ليشمل:
- مدنًا ومؤسسات ومرافق رقمية.
- اقتصادًا وموارد وإنتاجًا.
- تعليمًا وبحثًا وتعاونًا.
- وكلاء أكثر تخصصًا وقدرات تفاعلية.
